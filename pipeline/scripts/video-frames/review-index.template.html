Frame interval review

    How to use this page.
    1. Read the sheets below. Each tile is labeled with its time in the clip.
    2. Look for the smallest change between neighboring tiles that still shows the camera moving. Too similar wastes space and time; too different may not overlap.
    3. Type the interval and range you want in the builder at the bottom, then copy the command it prints. Run it with --dry-run first.

    These are previews for choosing only. Choosing an interval here does not check that frames overlap; the camera review before training does.
