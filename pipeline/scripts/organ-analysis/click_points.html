      Help
      • Mouse wheel: zoom in or out around the cursor (up to 32x).
      • Left click: place a point with the current label.
      • Right or middle mouse drag, or hold Space and drag with left: move the picture.
      • Drag an existing point with the left button to move it.
      • Ctrl+Z: undo the last change. F: fit the picture to the window.
      • The same label on one image can be used only once. The same label on different images means the same physical point.
      • Press "tape_ cm", type the number (for example 5), and the label becomes tape_5cm.
      • Export saves a JSON file. Import adds points from an earlier export. Points are also kept automatically in this browser.
      • Coordinates are in full-resolution image pixels: x to the right, y down, origin at the top-left corner of the top-left pixel (the centre of pixel i,j is i+0.5, j+0.5).
